# Art Studio VR

A VR art studio environment built in Unreal Engine — an interactive space
you can move through and manipulate.

- Interaction logic under `Content/RootCalledInteractions`
- Motion controller input and player setup under `Content/player`
- Custom environment art: `Models`, `walls`, `skybox`, `materials`

**Engine:** Unreal Engine · **Logic:** Blueprints

Purchased marketplace packs (`Painting_Portraits_1`, `LivingRoom_8`,
`FreeFurniturePack`, `Fab`) are excluded — licensed to me, not
redistributable. Renders and stills: https://artstation.com/ezgiiii
